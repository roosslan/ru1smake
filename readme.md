# ru1smake

Запускалась как служба и периодически делала скриншоты рабочего стола.

Программа решает задачу запуска процесса в сессии активного пользователя из контекста службы Windows.
Начиная с Windows Vista службы выполняются в изолированной сессии 0 и не имеют прямого доступа к рабочему столу пользователя,
поэтому для запуска GUI-приложения из службы требуется явно создать процесс в пользовательской сессии.

Функция `LaunchApplication` в [ru1smake.cpp](ru1smake.cpp):

1. получает идентификатор активной консольной сессии (`WTSGetActiveConsoleSessionId`);
2. находит процесс `winlogon.exe`, работающий в этой сессии;
3. получает и дублирует токен этого процесса (`OpenProcessToken`, `DuplicateTokenEx`), настраивает привилегию `SE_DEBUG_NAME` и привязывает токен к нужной сессии;
4. формирует блок окружения (`CreateEnvironmentBlock`);
5. запускает указанный исполняемый файл в пользовательской сессии (`CreateProcessAsUser`) на рабочем столе `Winsta0\Default`.

Делает скрины по заданному интервалу ru1smakehelper.exe - вместо него можно свой исполняемый файл.
